# 📊 Pesquisa de Satisfação — TudoWeb

Sistema desenvolvido em **Python** para realizar uma pesquisa de opinião com clientes da empresa fictícia **TudoWeb**.

O programa coleta informações dos entrevistados e registra sua opinião sobre o atendimento prestado.

## 🎯 Objetivo

O objetivo do projeto é praticar conceitos fundamentais de programação em Python, como:

* 🔄 Estruturas de repetição (`for`)
* 🔀 Estruturas condicionais
* 🎯 `match/case`
* ⌨️ Entrada de dados com `input()`
* 📝 Exibição de informações
* 🔢 Conversão de tipos de dados

## 📋 Funcionamento

Para cada entrevistado, o sistema solicita:

* 👤 Nome
* 🎂 Idade
* ⭐ Opinião sobre o atendimento

O entrevistado pode escolher uma das opções:

| Opção | Avaliação   |
| ----- | ----------- |
| `1`   | ⭐ EXCELENTE |
| `2`   | 👍 BOM      |
| `3`   | 👎 RUIM     |

Após a resposta, o sistema exibe os dados informados e a avaliação escolhida e de pois faz a soma de quais foram escolidos.
